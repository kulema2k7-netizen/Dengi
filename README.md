# 💰 Денежные средства

Простой журнал денег для телефона: сколько пришло, сколько потрачено и сколько осталось по каждому контрагенту.

## Возможности
- Общий баланс, приход и расход на главном экране
- Любое количество контрагентов, у каждого своя карточка с остатком
- Предупреждение, если расход превысил выданную сумму
- История всех операций с фильтром: сегодня, неделя, месяц, всё
- Выгрузка в Excel (CSV) и загрузка обратно
- Резервная копия (JSON) и восстановление
- Тёмная и светлая тема
- Работает без интернета, данные хранятся только на устройстве

## Установка на телефон
Открыть страницу проекта в Chrome → меню ⋮ → «Установить приложение».

## Хранение данных
Все данные лежат в памяти браузера на устройстве. Для надёжности периодически выгружайте резервную копию (кнопка ⤓).
